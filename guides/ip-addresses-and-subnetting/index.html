IP Addresses and Subnetting Made Simple

Understand IPv4 and IPv6, public vs private addresses, CIDR notation, subnet masks and how to size a subnet — with worked examples.

Video: What is an IP Address? // You SUCK at Subnetting // EP 1 (NetworkChuck). Embedded from YouTube in privacy-enhanced mode; all rights belong to the creator.

Every device on a network needs an address. Understanding how those addresses are structured — and how networks are carved into subnets — is foundational for anyone working in IT, DevOps or cloud infrastructure.

IPv4 in one paragraph

An IPv4 address is 32 bits, written as four decimal octets: 192.168.1.10. That allows about 4.3 billion addresses — far too few for today's internet, which is why we rely on NAT (many private devices sharing one public address) and are steadily adopting IPv6.

Public vs private

RFC 1918 reserves three ranges for private networks that are never routed on the public internet:

RangeCIDRTypical use
10.0.0.0 – 10.255.255.25510.0.0.0/8Enterprises, cloud VPCs
172.16.0.0 – 172.31.255.255172.16.0.0/12Docker, mid-size networks
192.168.0.0 – 192.168.255.255192.168.0.0/16Home and small-office routers

Your router translates between these and the public address you can see with our What Is My IP tool.

CIDR and subnet masks

CIDR notation 192.168.1.0/24 says the first 24 bits identify the network and the remaining 8 bits identify hosts. The equivalent subnet mask is 255.255.255.0 — 24 ones followed by 8 zeros in binary. Hosts per subnet = 2(32 − prefix), minus 2 reserved addresses (network and broadcast).

PrefixMaskUsable hosts
/30255.255.255.2522
/28255.255.255.24014
/26255.255.255.19262
/24255.255.255.0254
/22255.255.252.01,022
/16255.255.0.065,534

Worked example

You need four subnets of at least 50 hosts from 10.20.0.0/24. 50 hosts needs 6 host bits (64 addresses, 62 usable), so each subnet is a /26: 10.20.0.0/26, .64/26, .128/26 and .192/26. Verify each in the subnet calculator.

Cloud planning tips

  • Pick a large, unusual private block for each VPC (e.g. 10.42.0.0/16) so future VPN or peering connections don't overlap.
  • Cloud providers reserve extra addresses per subnet — AWS reserves 5 — so size generously.
  • Kubernetes needs separate ranges for nodes, pods and services; pods consume addresses fast.

IPv6 essentials

IPv6 addresses are 128 bits written in hex groups: 2001:db8:85a3::8a2e:370:7334 (:: compresses consecutive zero groups). The standard subnet for a LAN is a /64 — 18 quintillion addresses — so the scarcity mindset of IPv4 simply doesn't apply.
