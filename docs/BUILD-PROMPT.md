# Tech.Tools — Business Case & Phase-Wise Build Prompt

## 1. The idea (verdict first)

**Build Tech.Tools as a free, privacy-first, in-browser utility toolbox (developer / IT / security / SEO / design), wrapped in long-form guides, a curated software directory, and a B2B "Get Expert Help" lead-gen funnel.**

Why this beats the alternatives for this domain:

| Option | Traffic potential | Revenue per visit | Defensibility | Verdict |
|---|---|---|---|---|
| Tech news/blog | Medium, decays fast | Low (AdSense only) | Low — commodity content | ✗ |
| Pure SaaS directory (AI-tool-list clone) | Medium | Listing fees only | Low — 1,000s of clones | ✗ alone |
| Affiliate review site | Medium | High per conversion, low volume | Medium | Add-on later |
| **Utility toolbox + guides + directory + lead gen** | **High, evergreen, repeat** | **4 revenue lines** | **High (tool UX, compounding SEO)** | **✓** |

The logic:
1. **Utility queries are evergreen and repeat.** "json formatter", "dns lookup", "what is my ip", "password generator", "regex tester" are searched every day, every year. Users bookmark tools and come back — repeat visits are the cheapest traffic you'll ever get.
2. **The domain is an exact-match brand for the category.** "Tech.Tools" tells users and searchers exactly what they get; high trust → higher CTR in SERPs.
3. **Zero marginal cost.** Everything runs client-side as static HTML on free GitHub Pages hosting. 1 visit or 1M visits costs the same: $0.
4. **The audience is high-value.** Developers, IT admins and marketers are B2B buyers — this is what makes sponsorships and lead-gen worth far more than display ads.

## 2. Revenue model (assumption-driven — replace with real data at month 3)

| Line | Mechanism | Assumption | At 100k pageviews/mo |
|---|---|---|---|
| AdSense | Auto ads on tools + guides | RPM $3–$10 (global tech audience) | $300–$1,000 |
| Sponsorships | Tool sponsor $299, category $799, featured listing $49, sponsored guide $999 | 2 tool sponsors + 4 listings | ~$800 |
| Lead gen | Free audit → referral fee / margin on matched projects | 0.1% of visits → lead; 10% close; $300 avg referral | ~$300 |
| Donations | One-time / monthly pledges | 0.01% of visits × $20 | ~$200 |
| **Total** | | | **~$1,600–$2,300/mo** |

Sensitivity: lead-gen is the swing factor. One closed $25k cloud-migration project at a 10% referral fee = $2,500 — more than a month of AdSense. **Optimise the funnel before chasing more pageviews.**

Traffic path to 100k PV/mo: 38 tools × ~1–3k visits each once ranked (6–12 months) + guides + repeat users. Scaling to 100+ tools is the main growth lever.

## 3. AdSense approval strategy (built in)

AdSense commonly rejects tool sites for "low-value content". Counter-measures implemented:
- Every tool page carries 300–600 words of **original** how-to + explainer + FAQ (with FAQPage schema).
- 10 long-form original guides (6–10 min reads).
- Privacy Policy with Google's required advertising-cookie disclosures, Terms, Cookie Policy, Disclaimer, About (editorial policy), Contact form, Accessibility.
- `ads.txt` with the publisher ID, `google-adsense-account` meta tag and the AdSense script in every `<head>`.
- No placeholder/lorem text, no fake reviews or testimonials, no copyrighted embeds outside YouTube's official player.
- Clear navigation, HTML sitemap + XML sitemap, fast static pages, mobile-responsive.
- **Action for owner:** connect the custom domain *before* applying (AdSense reviews the root domain, and `ads.txt` must be at `https://tech.tools/ads.txt`). Enable AdSense's Privacy & Messaging (Google-certified CMP) for EEA/UK visitors.

## 4. Phase-wise build prompt

Use these prompts in order with an AI coding assistant (or as a spec for a developer). Each phase is shippable.

---
### Phase 0 — Foundations
> Create a static website for the domain **Tech.Tools** ("Tech Tools") that can be hosted for free on GitHub Pages (repo `tech-tools`). No build server: plain HTML, CSS and vanilla JS, generated by a Python script (`scripts/build.py`) from data files so 100+ pages stay consistent. Use relative links everywhere so the site works both at `username.github.io/tech-tools/` and at `https://tech.tools/`. Add `.nojekyll`, `robots.txt`, `sitemap.xml`, `ads.txt` (`google.com, pub-6620975821265271, DIRECT, f08c47fec0942fa0`), `manifest.webmanifest`, an SVG favicon and a 1200×630 OG image.

### Phase 1 — Design system & shell
> Build a modern, distinctive design system: "precision instrument" aesthetic — graphite ink, signal-cyan primary, amber accent (the dot in the logo "Tech.Tools"). Fonts: Space Grotesk (display), Inter (body), JetBrains Mono (code). Light + dark themes (respect system preference, toggle saved in localStorage). Responsive down to 320px with no horizontal scroll. Every page gets: (1) a top banner reading "Contact, if you are interested in this website / domain name / Sponsorship / Advertisement / Partnership" linking to `https://web.works/contact`; (2) sticky header with nav, Ctrl/⌘+K instant search modal, theme toggle and a "Free Tech Audit" CTA; (3) footer with newsletter form, category links, business links, legal links and a short trademark disclaimer; (4) cookie notice; (5) dismissible sticky lead-gen CTA after scroll. Insert in every `<head>`: `<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-6620975821265271" crossorigin="anonymous"></script>` and `<meta name="google-adsense-account" content="ca-pub-6620975821265271">`.

### Phase 2 — Private contact routing
> All forms (contact, lead gen, newsletter, donations, advertising, partnerships, directory submission, contest entries, job applications) must deliver to one private inbox **without the address ever appearing in HTML, JS strings or the rendered page**. Store the address reversed and split in JS, reassemble at submit time, and POST JSON to the FormSubmit AJAX endpoint with a honeypot field, subject prefix "[Tech.Tools]", and table template. "Email us" links build a `mailto:` only on click. On network failure, offer a click-to-email fallback.

### Phase 3 — Tools (core traffic engine)
> Build 38 fully working, client-side tools, each on its own SEO page at `/tools/<slug>/`: JSON formatter/validator, Base64, URL encoder/parser, JWT decoder, UUID v4/v7, hash generator (MD5/SHA-1/256/384/512), regex tester, Unix timestamp converter, cron explainer with next runs, text diff, HTML entities, case converter, number base converter (BigInt), YAML⇄JSON, JSON⇄CSV, password generator + passphrases, password strength checker, QR code generator, What is my IP, DNS lookup (DNS-over-HTTPS), CIDR/subnet calculator, user-agent/browser info, HTTP status codes, meta tag generator with SERP preview, robots.txt generator (with AI-crawler blocking), UTM builder, word counter, lorem ipsum, text cleaner, color converter, WCAG contrast checker, CSS gradient generator, box-shadow generator, image compressor/resizer (canvas, no upload), image to Base64, data size converter, download time calculator, aspect ratio calculator. Each page: breadcrumbs, H1, tool workspace above the fold, copy/download buttons, "how to use" steps, 200–400 word original explainer, FAQ with FAQPage schema, SoftwareApplication schema, related tools, related guides, lead-gen card, sponsor slot. Track "recently used" tools in localStorage.

### Phase 4 — Content for authority & AdSense
> Write 10+ original long-form guides (JSON, regex, Git/GitHub, DNS, password security, Base64, cron, Linux CLI, HTTPS/TLS, IP subnetting), each with a verified YouTube embed (privacy-enhanced, click-to-load), Article + VideoObject + Breadcrumb schema, internal links to matching tools, and a lead-gen sidebar. Build a video library page. Publish About (with editorial policy), Privacy (with Google advertising-cookie disclosures and opt-out links), Terms, Cookies, Disclaimer, Accessibility, Trademark & Copyright, HTML sitemap and a 404 page.

### Phase 5 — Lead generation (highest-value page)
> Build `/get-expert-help/`: hero promise ("Get the right expert for your tech project — in 24 hours"), trust chips, 3-step process, and a 3-step qualification form (services multi-select + goal → budget, timeline, company size, description → name, work email, company, phone, country, consent). Progress bar, per-step validation, success message. Add a short "quick lead" form on the home page, lead cards on every tool and guide page, and a sticky CTA. No fake testimonials or invented statistics.

### Phase 6 — Monetisation pages
> `/advertise/` with 4 sponsorship tiers (Directory Featured $49/mo, Tool Sponsor $299/mo, Category Takeover $799/mo, Sponsored Guide $999) and a media-kit form. `/partners/` with partnership types and proposal form. `/support/` donation page: one-time/monthly toggle, preset amounts, fund allocation (operations & hosting, new tools, promotion & marketing, hiring talent, contests & prizes) with progress bars, pledge form, and optional instant-pay buttons driven by `assets/js/config.js` (Stripe/PayPal/Ko-fi/Buy Me a Coffee/GitHub Sponsors links). `/contests/` with a Build Challenge, prize tiers, official rules (18+, no purchase necessary, judging criteria) and entry form. `/careers/` with freelance roles and a talent application form.

### Phase 7 — Directory
> `/directory/` with 45+ curated tools in 8 categories, pricing tags, instant filter + search, a labelled "Featured slot" upsell, and `/directory/submit/` with free-review vs featured-listing options.

### Phase 8 — QA, launch & growth
> Headless-browser test every page: no JS errors, every tool renders, no horizontal overflow at 375px, all internal links resolve, the private email never appears in the DOM. Push to GitHub, enable Pages from `main` / root, connect `tech.tools` (CNAME file + DNS A records 185.199.108–111.153), enforce HTTPS, submit sitemap to Google Search Console, then apply to AdSense. Growth loop: add 5 tools/month based on Search Console queries, one guide per new tool, pitch sponsors once a tool passes 1k visits/month.
