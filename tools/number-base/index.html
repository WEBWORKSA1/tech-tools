How to use the Number Base Converter

  1. Type into any base field.
  2. All other fields update instantly.
  3. Copy whichever representation you need.

About this tool

Computers think in binary, engineers read memory and colours in hexadecimal, Unix permissions are octal, and humans count in decimal. This converter keeps all of them in sync as you type, using JavaScript's BigInt so even 256-bit values (like cryptographic keys) convert without losing precision.

Quick reference

DecimalHexBinary
10A1010
255FF1111 1111
409610001 0000 0000 0000

Prefixes such as 0x, 0b and 0o are accepted and ignored.

Frequently asked questions

Does it support fractions?

Integers only — fractional base conversion is lossy and rarely needed.

Negative numbers?

Yes, with a leading minus sign (not two's complement).
